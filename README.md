# No More Pointless Quests

A small **Battle Brothers** mod that removes the low-value contracts from the contract pool and makes caravan escorts worth taking.

---

## Features

- **Deliver Item** contracts are no longer offered (northern settlements and southern city states)
- **Discover Location** contracts are no longer offered (northern settlements)
- **Escort Caravan** contracts always get an **extra ambush**: the attackers are spawned as soon as the caravan sets out, on top of vanilla's usual encounter

Contracts that are already active are not affected.

---

## Requirements

- Modern Hooks
- Modding Standards and Utilities (MSU)
- Made for Reforged (loads after it)

## Installation

Download the zip from the latest [release](../../releases) and put it (unextracted) into the game's `data` folder.
The mod is **safe to add to or remove from an existing savegame**.
